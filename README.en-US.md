

### Introduction
This is a general-purpose game framework I developed using Unity. It integrates the tolua Framework and supports sproto protocol communication (including C# and Lua). It encapsulates various managers: ResourceManager, NetworkManager, ConfigManager, VersionManager, AudioManager, LogManager, UIManager, EffectManager, AtlasManager, EventManager, and common utility classes.

Unity Version Used: 2021.1.9f1c1
The accompanying server-side uses the skynet framework.
